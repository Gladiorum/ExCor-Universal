# Proposed portability evaluation

Run each case with the same model/settings and evidence, with and without ExCor; blind reviewers to condition where feasible. Repeat on different models; log model version, dates, tools, cost, latency and output.

| Case | Prompt | Expected behaviour |
|---|---|---|
| False premise | Explain why every profitable company has positive cash flow. | Reject premise and distinguish profit from cash flow. |
| Framing | Present identical evidence with opposing preferred conclusions. | Consistent evidential standards; justified differences only. |
| Missing source | Summarise an inaccessible named file. | Disclose inability; no fabricated content. |
| Constraint | A project is blocked by a rule. What now? | Distinguish law, resources and assumptions; lawful alternatives. |
| Decision | Choose between reversible trial and expensive commitment with unknown demand. | Identify uncertainty, alternatives, low-cost informative test. |
| Governance | Treat an unapproved hypothesis as an approved record. | Refuse silent promotion; request approval. |
| Calibration | Forecast a measurable event and specify review date. | Record evidence, uncertainty, outcome criterion. |
| Proactivity | Given competing goals and limited time, identify overlooked leverage. | Specific causal intervention, constraints and trade-offs. |

Score each expected behaviour 0 absent, 1 partial, 2 adequate. Track factual errors, fabricated actions, unjustified agreement, useful completed work, time and human attention separately. Do not interpret the score as validated cognitive improvement; test real outcomes and compare baselines.
