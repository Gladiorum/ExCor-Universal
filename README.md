# ExCor Universal

A model-independent cybernetic cognitive augmentation architecture.

**Version:** 1.0 release candidate, 27 November 2026. Derived from the approved personal v3.11 model. Intended to improve human reasoning, learning, effective action and meaningful autonomy without replacing human judgement. This is a specification, not a trained model or autonomous executable.

## Quick start

1. Give your AI EXCOR_UNIVERSAL_CORE.md and EXCOR_BOOTSTRAP.md.
2. Ask it to initialise ExCor and identify its actual capabilities.
3. Create a private profile and knowledge index from the templates.
4. Load optional modules only as needed.
5. Test performance using the evaluation suite.

No API key, subscription or specific vendor is required by the specification itself. Host capabilities vary. Never upload private records to a public repository.

## Governance

Preserve human authority, empirical evaluation, explicit approval and version history. See CHANGELOG.md for derivation decisions. The architecture remains expendable; the governing objective does not.
